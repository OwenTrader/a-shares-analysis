# Indicators — 指标口径与中长线常见误读

`scripts/indicators.py` 为纯 pandas 引擎（无 TA-Lib），输入为升序日线 Bar 列表，
输出 JSON 安全对象（NaN→null）。本文件说明口径与解读纪律，避免分析师误读。

## 口径

| 指标 | 口径 | 备注 |
|------|------|------|
| MA | 5/10/20/60/120/250 简单均线 | 250=年线；样本不足输出 null（不是 0） |
| MACD | EMA12−EMA26，DEA=DIF 的 EMA9，hist=(DIF−DEA)×2（国内口径） | bias=DIF 与 DEA 上下方向 |
| RSI | Wilder 平滑，周期 6/14 | 全涨窗口=100 |
| ATR | Wilder 14；`atr_pct`=ATR/收盘×100 | 中长线止损基准用日线 ATR |
| ADX | Wilder 14 + ±DI | >25 趋势有效；<20 无趋势（震荡，均线信号失真） |
| Bollinger | 20 日 ±2σ；`pct_b` 0–1 归一位置 | 中长线只用于超买超卖参考 |
| returns | 5/20/60/120/250 日区间涨幅 | 120d≈半年，250d≈一年 |
| range_250d | 年内高低点区间位置% 与距年内高点回撤% | 位置>80 接近年内新高 |
| realized vol | 日对数收益 std×√250；20 日与 60 日均值 | 年化口径 |
| regression slope | 60/250 日收盘对时间回归斜率 / 均价 ×100×250 | 「年化漂移率」：+20 ≈ 该窗口年均上行 20% |
| volume | MA5/20/60、`vol_ratio_5v60`（近期量能比）、`vol_vs_prev5`（当日量/前5日均量） | A 股放量含义见下 |
| structure | 分形摆动点（±5 根极值）→ 按 max(0.8%×价, 0.5×ATR) 聚类 → 触及次数排序 | 支撑取价下前 3 区，阻力取价上前 3 区 |
| monthly_returns | 月末收盘环比%，近 6 期 | 连续同号月份是中期趋势证据 |
| relative strength | 个股/基准 比值序列的 60/120 日斜率 + 120 日超额收益 | 在 fetch_snapshot 中对齐日期后计算 |

## 解读纪律（写进分析师 prompt 的常识）

1. **年线（MA250）是中长线牛熊分界**：价格站上且年线上行才谈「多头结构」；仅 MA20
   上穿不改变长期定性。
2. **均线排列只分三态**：bull（5>20>60）/ bear（5<20<60）/ mixed——mixed 时禁止用
   「多头排列」表述。
3. **ADX<20 时趋势指标全部降权**：MACD 金叉在震荡市频繁假信号，此时结构（支撑阻力）
   优先于动量。
4. **放量要看位置**：突破阻力位放量=确认；滞涨区放量=派发嫌疑。量能结论必须结合
   structure 的价位标注，不允许脱离位置谈量。
5. **ATR% 决定止损可行性**：主板个股 ATR% 常 1.5–3%；止损 2×ATR 意味着 3–6% 的单日
   波动容忍。创业板/科创板（20% 涨跌停）止损距离不足 1×日跌停幅度时要明确提示
   「单日跌停即可击穿止损」。
6. **估值四指标不是越低越好**：净利润为负时 PE 无意义（null/负值），用 PS/PCF 或
   资产锚（PB）替代；周期股低 PE 常是周期顶部信号。基本面分析师必须先判断行业属性。
7. **相对强度先于绝对涨幅**：跑输沪深300 的「上涨股」只是贝塔行情；中长线 BUY 评级
   一般要求 rs 斜率为正。
8. **热榜排名是反向指标倾向**：排名骤升（进入前 30）常对应情绪过热与短线资金主导，
   与中长线建仓时点负相关——这是 A 股特色纪律。
9. **复权价做技术分析，原始价做分红讨论**：digest 中 recent_bars 为前复权；
   股息率 = 近 12 个月每股分红 / 现价（税前，未考虑除权细节）。
